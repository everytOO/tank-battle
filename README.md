# 坦克大战 Tank Battle

经典红白机风格（Battle City）的 HTML5 坦克大战游戏，纯单文件实现，无需任何依赖。

## 在线游玩

直接用浏览器打开 `index.html` 即可，或访问 GitHub Pages（如果在仓库设置中开启）。

## 操作方式

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` 或方向键 | 移动坦克 |
| `空格` | 开火 |
| `P` | 暂停 / 继续 |
| `Enter` | 开始 / 重新开始 |

## 游戏规则

- 保护屏幕底部的金色老鹰基地，基地被击毁则游戏结束
- 消灭每一关的所有敌方坦克即可进入下一关
- 击毁敌方坦克 +100 分，过关 +500 分
- 初始 3 条命，被击毁后在基地旁重生（有短暂无敌护盾）

## 地形

| 地形 | 特性 |
| --- | --- |
| 🧱 砖墙 | 可被子弹击破 |
| ⬜ 钢墙 | 无法击破 |
| 🌊 河流 | 坦克不能通过，子弹可以飞越 |
| 🌲 树林 | 可以通行，会遮挡视线（隐蔽） |

## 技术说明

- 单个 `index.html` 文件，内联全部 CSS 与 JavaScript
- 使用 Canvas 2D 渲染，`requestAnimationFrame` 游戏循环
- 26×26 网格地图，3 个手工设计的关卡模板循环递进，敌人数量和速度随关卡提升
- 敌方坦克具备简单 AI：随机巡逻、趋向基地方向、随机开火
